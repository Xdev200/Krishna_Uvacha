## 🌐 Overview

This portal serves as the primary touchpoint for the Krishna Uvacha mobile ecosystem. It provides critical information for users and ensures compliance with global app store standards.

- 💎 **Seamless Branding**: Implements the "Clinical Luxury" design system for a consistent experience from web to mobile.
- 📜 **Compliance Ready**: Includes official Privacy Policy and Terms of Service.
- 🚀 **Feature Showcasing**: Highlights the core mobile app experiences in a modern landing page.

---

## 🏗️ Project Structure

The portal is built as a lightweight, high-performance static site.

- **`index.html`**: The main gateway, featuring premium animations and feature highlights.
- **`privacy.html`**: Legally compliant Privacy Policy for app store submission.
- **`terms.html`**: Terms of Service governing app usage.
- **`css/style.css`**: The central design system implementation (Vanilla CSS).
- **`assets/`**: High-quality visual assets and brand elements.

---

## 🎨 Design Philosophy

The web portal adheres to the **Clinical Luxury** design tokens:

| Element | Specification |
| :--- | :--- |
| **Typography** | Newsreader (Serif) for Wisdom, Inter (Sans) for Clarity |
| **Color Palette** | Cream backgrounds with Gold and Saffron highlights |
| **Aesthetics** | Minimalist, serene, and premium |

---

## 🚀 Deployment

As a static gateway, this portal can be deployed instantly to any modern hosting platform:

1. **GitHub Pages**: Simply push the `web` directory content to a `gh-pages` branch.
2. **Netlify/Vercel**: Point the build settings to the `web` folder.
3. **S3/Cloudfront**: Ideal for high-scale global delivery.
